🎬 Online Movie Ticket Booking

A simple and responsive Online Movie Ticket Booking Website built using HTML, CSS, and JavaScript.

The website allows users to select a movie, enter their details, choose the number of tickets, calculate the total bill, and view their booking history.

🌐 Live Demo

Visit the website:
https://soumilikuila.github.io/online-ticket-booking/

✨ Features

- 🎬 Display available movies
- 🎟️ Book movie tickets
- 👤 Enter customer name
- 📱 Enter phone number
- 🎫 Select number of tickets
- 💰 Automatic total bill calculation
- 💺 Real-time seat availability
- 📋 Booking history
- ✅ Booking confirmation
- 📱 Mobile-friendly responsive design

🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Select a movie.
5. Enter customer details.
6. Select the number of tickets.
7. Click Confirm Booking.

💻 How It Works

1. Users select a movie from the available movie list.
2. The selected movie and ticket price are displayed.
3. Users enter their name and phone number.
4. Users choose the number of tickets.
5. JavaScript checks seat availability.
6. The total ticket price is calculated automatically.
7. Available seats are updated after booking.
8. The booking is added to the booking history.
